# A-roll : les rushes principaux

La personne qui parle, l'interview, la voix. Un fichier par prise (`.mp4`,
`.mov`), avec son son d'origine. Nom simple, sans espace ni accent
(`interview-maire.mp4`) : il devient celui de la vidéo finale.

Les rushes ne vont pas dans git : l'original reste sur le Drive, on en dépose
une copie ici le temps du montage.
